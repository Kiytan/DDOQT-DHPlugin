DDOQT for Dungeon Helper

A Dungeon Helper plugin that tracks the quests you complete in DDO and syncs them to the DDO Quest Tracker.

Download the latest release

Installing

  1. Download DDOQT_<version>.zip from the latest release.
  2. In Dungeon Helper 5, go to Settings → "Add plugin from zip file" and pick it.
  3. Log in to a character and open the Quest Tracker window from the toolbar.

Once installed, Dungeon Helper keeps the plugin up to date by itself.

More information

Usage, known issues and build instructions are in the project's README on GitHub.

This site also hosts the plugin's update feed, which Dungeon Helper checks for new versions.
